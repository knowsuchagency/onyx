# Marketing — UI Kit

A small public-site sketch for Onyx. **Purposely minimal** — only one render was provided as source material, so I built two screens worth of marketing chrome using the same vocabulary as the console (dark canvas, indigo accent, terminal voice). Anything beyond this — pricing, docs, blog — should be commissioned with real direction.

## Files
- `index.html` — landing page entry.
- `app.jsx` — page composition.
- `Hero.jsx` — full-bleed hero with live "console preview" frame.
- `FeatureGrid.jsx` — three-up feature row, terminal-style.
- `ConsoleDemo.jsx` — a tiny static reproduction of the orchestration board for the hero.
- `Footer.jsx` — site footer.

This is **derived**, not specified. Flagged for design review.
